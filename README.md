# Smart Industrial Safety Helmet for Industrial Workers

## Project Overview

This project focuses on developing an IoT-based smart safety helmet designed to improve worker safety in hazardous environments such as mining and industrial sites.

The system integrates health monitoring, GPS location tracking and wireless communication to help detect emergencies and support faster rescue operations.

## Problem Statement

Workers in mining and industrial environments face health risks and emergencies where immediate medical assistance may not be available. Traditional safety equipment often lacks real-time health monitoring and location tracking.

This project proposes an integrated smart helmet to address these challenges.

## Hardware Components

- **ESP32:** Main microcontroller responsible for processing sensor data.
- **MAX30102:** Pulse oximeter sensor for heart rate and oxygen-level monitoring.
- **NEO-6M GPS:** Provides geographical location information.
- **LoRa SX1278:** Enables long-range, low-power wireless communication.

## Working Methodology

1. The MAX30102 sensor monitors the worker's heart rate and oxygen levels.
2. The ESP32 processes the collected sensor information.
3. The NEO-6M GPS module provides the worker's location.
4. The LoRa SX1278 module transmits the collected information to a central monitoring system.
5. When abnormal health conditions are detected, an emergency alert can be triggered to support timely intervention.
